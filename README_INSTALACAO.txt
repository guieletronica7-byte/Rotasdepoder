ROTAS DE PODER — APP WEB (PWA) PARA ANDROID E IPHONE

1. Extraia toda esta pasta em um serviço de hospedagem HTTPS (como GitHub Pages, Netlify ou Vercel).
2. Abra o endereço /index.html no celular. O jogo já funciona normalmente no navegador.
3. Android/Chrome: menu ⋮ > Instalar aplicativo ou Adicionar à tela inicial.
4. iPhone/Safari: Compartilhar > Adicionar à Tela de Início > Adicionar.
5. Depois da primeira visita ao site, o app guarda seus arquivos para uso offline.
6. A partida salva no próprio dispositivo (localStorage); dados não são enviados para servidores.

VERSÃO SEM HOSPEDAGEM: abra ROTAS_DE_PODER_MOBILE_2_0.html no navegador. O HTML é autocontido, mas instalação PWA e salvamento dependem do navegador/HTTPS.

Jogo fictício e satírico, não representa acontecimentos reais.
